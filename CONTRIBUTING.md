# Contributions

Décrire le problème, fournir une reproduction avec fichiers synthétiques et des journaux nettoyés. Ne pas joindre de musique personnelle, clés, mots de passe ou bases DJ personnelles.

Préserver les quatre moteurs, TaskHub, la durabilité SQLite et les performances. Toute correction doit être minimale, démontrée et testée ; ne pas affaiblir les assertions ni présenter un test ignoré comme réussi. Ne jamais désactiver les protections Windows pour faire passer un test.

Les contributions au code original seront sous GPL-3.0-or-later, sous réserve de la confirmation de la licence initiale avant publication. Les auteurs devront avoir les droits nécessaires sur leurs contributions. Aucun envoi de signature depuis une pull request non approuvée.
